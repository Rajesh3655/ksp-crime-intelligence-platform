# Technical Presentation Outline

1. Problem: FIR data is rich but underused for prevention.
2. Solution: CIAP converts official FIR records into intelligence scores, graphs, forecasts, and recommendations.
3. Architecture: Catalyst Functions, AppSail AI service, Data Store, NoSQL, Cache, Cron, Circuits, SmartBrowz.
4. AI: DBSCAN, Isolation Forest, XGBoost, Sentence Transformers, NetworkX.
5. Demo: dashboard, geo replay, graph, copilot, SCRB report, explainable prediction.
6. Governance: model registry, drift detection, prediction audit, human feedback.
7. Impact: prevention, faster investigation, better deployment, auditable AI.
