# CIAP Live Demo Script

Audience: DGP, SCRB officers, and technical judges.

1. Open Executive Dashboard.
   - Show statewide risk, hotspots, repeat offenders, anomaly count, and model version.
   - Message: CIAP converts official FIR data into operational intelligence.

2. Open Hotspot Prediction.
   - Move the time slider from Week 1 to Week 12.
   - Enable prediction and police deployment overlays.
   - Message: this is not a static heatmap; it replays evolution and recommends patrol deployment.

3. Open Knowledge Graph.
   - Select the highest-risk accused node.
   - Explain edges: same FIR, address, phone, vehicle, gang, MO, police station, and district.
   - Message: link analysis becomes automatic because the graph is generated from official entities.

4. Open Crime DNA and Repeat Offender intelligence.
   - Show MO similarity, associates, last seen, district count, and gang score.
   - Message: serial offenders and organized groups become measurable.

5. Open AI Copilot.
   - Ask: "Predict next week's hotspots" and "Who is connected to A1?"
   - Message: officers can query intelligence without learning dashboards.

6. Open SCRB Report.
   - Show executive summary, district ranking, trends, predictions, and recommended patrols.
   - Message: SmartBrowz can export judge-ready and board-ready intelligence reports.

7. Close with Explainable AI.
   - Show prediction, why, important features, historical cases, confidence, and recommended action.
   - Message: every AI result is auditable and operationally useful.
